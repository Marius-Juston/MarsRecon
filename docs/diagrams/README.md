# Generated diagrams

This directory holds **pre-rendered SVGs** produced by the scripts under
`scripts/architecture/` during the documentation build. The SVGs are **not** committed —
they are regenerated by CI on every docs build, so they always reflect the current pipeline.

To render them locally before serving the site:

```bash
uv run python scripts/architecture/depthfm_pipeline_diagram.py
uv run python scripts/architecture/marsclip_diagram.py
```

Outputs should end up here (paths referenced in `docs/architecture/*.md`):

- `pipeline_overview.svg`
- `adapter_detail.svg`
- `training_step.svg`
- `marsclip.svg`

If the upstream scripts write to a different location, the `docs-ci.yml` workflow copies
them into this directory before `properdocs build`.
